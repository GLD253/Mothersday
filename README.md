# 🌹 Mother's Day Greeting Card Website

A beautiful, interactive Mother's Day greeting card website with flowers, confetti, personal messages, and music!

## Features

✨ **Interactive Greeting Card** - A gorgeous animated card with Mother's Day wishes

🌸 **Floating Flowers** - Animated flowers floating across the background

💌 **Personal Messages** - Add custom messages to the card

🎵 **Song Highlight** - Embed and play a special song for mom

🎉 **Confetti Celebration** - Trigger colorful confetti animations

💕 **Floating Hearts** - Send love with floating heart animations

📱 **Responsive Design** - Works beautifully on all devices

## How to Use

1. **Add a Personal Message:**
   - Type your special message in the input field
   - Click "Add Message" or press Enter
   - Your message will appear on the card

2. **Play the Song:**
   - Click the play button on the audio player
   - Your special Mother's Day song will play

3. **Celebrate:**
   - Click "🎉 Celebrate!" to trigger confetti
   - Click "💕 Send Love" to send floating hearts
   - Click "Reset" to clear the message and restart

4. **Add Your Song:**
   - Replace `your-song.mp3` in `index.html` with your own song file
   - The audio player will automatically work with MP3, WAV, and other formats

## Files

- `index.html` - Main webpage structure
- `style.css` - Beautiful styling and animations
- `script.js` - Interactive features (confetti, hearts, messages)
- `README.md` - This file

## Customization

### Change the Song
1. Add your audio file to the repository
2. Update the `src` in the audio tag in `index.html`:
   ```html
   <source src="your-song.mp3" type="audio/mpeg">
   ```

### Customize Colors
Edit the CSS in `style.css` to change:
- Background gradient (line ~14)
- Card colors (line ~113)
- Button colors (various button classes)

### Add More Decorations
- Add more emojis to the flower decorations
- Modify animation speeds in CSS
- Change confetti colors in `script.js` (line ~47)
